# FirstDev Design System

Applies to every UI, brand and marketing surface (frontend parts, docs sites, generated reports).

## Theme

Dark mode first. Inspired by modern urban architecture, night city grids and terminal interfaces.

## Palette

| Token | Value | Use |
|---|---|---|
| `bg-base` | `#0B0F19` | Deep Obsidian: page background |
| `bg-surface` | `#111827` | Slate Dark: cards, panels |
| `accent-primary` | `#00F2FE` | Cyber Cyan: active states, AI Match Scores, primary highlights |
| `accent-verified` | `#FFB703` | Industrial Yellow / Neon Amber: verified skill badges, alerts, GitHub metrics |
| `text-primary` | `#F8FAFC` | Pure White / Metallic Silver: sharp typography |

## Typography

- UI text: Inter or Geist.
- Code blocks, terminal logs, system metrics: JetBrains Mono.

## Visual motifs

- Glassmorphic cards with glowing neon borders.
- Subtle grid patterns that read as city layouts.
- Code-bracket silhouettes (`< / >`).

## Logo concept

An urban minimalist monogram merging "FD" with a skyscraper skyline silhouette built from code brackets (`< / >`).
